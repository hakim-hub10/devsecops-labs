# DevSecOps Labs

This repository contains hands-on infrastructure security, Kubernetes, and DevOps experiments.

## Repository Structure

- docs/ – Security documentation and architecture reports
- infrastructure/ – VPN, firewall and host hardening configurations
- kubernetes/ – k3s deployments and stateful workloads
- docker/ – Container experiments and service setups
- labs/ – Practical DevSecOps and networking labs

## Implemented Security Controls

- SSH hardening (key-based auth, root disabled)
- WireGuard VPN-based administrative isolation
- UFW firewall with restricted SSH
- Fail2ban intrusion mitigation
- 2FA-enabled cloud account
